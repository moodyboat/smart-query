## 📝 **体验提示词管理功能**

### **1. 进入提示词管理**

点击左侧边栏的 **"📝 提示词管理"** 按钮

### **2. 查看预设场景**

你应该看到6个预设场景卡片：

1. **通用查询** 🔍 - 通用的数据查询和分析
2. **销售分析** 📈 - 销售数据分析和报表
3. **用户分析** 👥 - 用户行为分析和画像
4. **财务分析** 💰 - 财务数据分析和报表
5. **运营监控** 📊 - 运营指标监控和预警
6. **数据挖掘** 🧠 - 机器学习模型训练

### **3. 探索场景提示词**

**选择一个场景**：
- 点击任意场景卡片（比如"销售分析"）
- 查看该场景的提示词列表
- 默认提示词会有"默认"标签

**查看提示词详情**：
- 点击某个提示词的"查看"按钮
- 阅读专业的提示词内容
- 查看变量配置和模型参数

### **4. 创建自定义提示词**

**体验创建流程**：
1. 选择一个场景（比如"通用查询"）
2. 点击"添加提示词"按钮
3. 填写表单：
   - **名称**：`我的测试提示词`
   - **编码**：`my_test_prompt`
   - **类型**：选择 `system`
   - **描述**：`这是我的第一个自定义提示词`
   - **内容**：输入一些测试内容
4. 点击"保存"

### **5. 测试提示词编辑**

**编辑现有提示词**：
- 找到你刚创建的提示词
- 点击"编辑"按钮
- 修改内容
- 保存更改

**设置默认提示词**：
- 点击某个提示词的"设为默认"按钮
- 该提示词应该获得"默认"标签
- 其他提示词的"默认"标签消失

## ⚙️ **体验元数据配置功能**

### **1. 进入元数据配置**

点击左侧边栏的 **"⚙️ 元数据配置"** 按钮

### **2. 选择数据源**

- 在顶部的数据源选择器中选择一个数据源
- 界面会显示该数据源的元数据配置

### **3. 查看表和字段配置**

**切换到"表和字段配置"选项卡**：
- 查看树形结构的表和字段
- 树形结构展示数据表的层级关系
- 每个节点显示配置类型和属性

### **4. 管理业务术语**

**切换到"业务术语"选项卡**：
- 查看现有的业务术语列表
- 使用搜索框筛选术语

**创建新的业务术语**：
1. 点击"添加术语"按钮
2. 填写表单：
   - **业务术语**：`销售额`
   - **名称**：`销售总额`
   - **描述**：`企业在一定时期内销售商品或服务所获得的总收入`
   - **别名**：输入 `营业额`，按回车，再输入 `营收`，按回车
3. 点击"保存"

### **5. 配置维度指标**

**切换到"维度指标"选项卡**：
- 左侧显示维度列表
- 右侧显示指标列表
- 可以看到哪些字段被标记为维度或指标

## 🔧 **如果遇到问题**

### **问题1：看不到新按钮**

**解决方法**：
1. 刷新浏览器页面 (F5)
2. 清除浏览器缓存后重试
3. 检查前端服务是否正常运行

### **问题2：点击按钮没有反应**

**解决方法**：
1. 打开浏览器开发者工具 (F12)
2. 查看Console标签是否有错误信息
3. 检查Network标签确认API请求是否成功

### **问题3：数据加载失败**

**解决方法**：
1. 确认后端服务正在运行 (端口9000)
2. 检查数据源配置是否正确
3. 查看浏览器Console的网络请求详情
